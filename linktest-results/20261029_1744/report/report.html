What this test does and does not show

  • It measures application data (UDP test packets) leaving the Cruza's companion Pi and arriving at each quad's Pi, over whatever network path the Pis were using. "Delivered" is counted by the quad itself when its log is collected.
  • It does not send anything to either flight controller and is not a test of flight control over this path.
  • Round-trip time includes the quad's reply leg. Clock offsets between the Pis are estimated, not assumed zero.
  • "Route" is the Cruza Pi's outgoing interface (e.g. wwan0 = LTE, wlan0 = Wi-Fi, tailscale0 = VPN). "VPN path" shows whether Tailscale reached the quad directly or through a DERP relay server.
  • If the Cruza's Wi-Fi was connected, some data may have used Wi-Fi rather than LTE; see the Wi-Fi column.

Data files: per-probe, per-window, outage, burst and distance tables are saved as CSV next to this report, with summary.json.
